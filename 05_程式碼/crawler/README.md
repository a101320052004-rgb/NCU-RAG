# 國際處網站爬蟲（校園 RAG 專案）

把國際處網站（中英文）和住宿服務組的頁面、附件抓下來，自動標記主題與適用身分，切成 RAG 可以直接匯入的段落。

## 第一次執行（Windows）

在這個資料夾按右鍵 →「在終端機中開啟」，然後依序執行：

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

接著用記事本打開 `config.yaml`，把第一行 `user_agent` 裡的 `your-email` 換成你們的信箱。網站管理者看到流量時，才知道是誰在爬、可以聯絡誰。沒換的話，程式會拒絕執行。

先小量試跑 20 頁，確認抓得到內容：

```powershell
python crawler.py --site oia --max-pages 20
```

沒問題再爬完整版：

```powershell
python crawler.py
```

之後每次重新打開終端機，只要先執行 `.venv\Scripts\activate`，再執行 `python crawler.py`。

## 爬完會產生什麼

結果在 `04_知識庫資料/原始資料/<網站名稱>/`：

| 檔案 | 內容 | 給誰用 |
| --- | --- | --- |
| `report.md` | 爬取報告：主題覆蓋、缺哪類資料、期限已過的公告、可能過期的頁面、高風險頁面、跳過的網址 | **先看這個** |
| `documents.jsonl` | 每頁或每個附件一筆，含全文和所有標記 | 人工檢查、之後整理 |
| `chunks.jsonl` | 切好的段落，每段帶有主題、身分、語言、風險等標記 | 直接匯入向量資料庫 |
| `skipped.jsonl` | 沒抓到的網址和原因 | 除錯 |
| `state.json` | 上次爬到的內容指紋 | 下次執行時比對新增、修改、消失的頁面 |
| `raw/` | 原始 HTML 和附件檔 | 備查 |

## 自動標記的欄位

| 欄位 | 意思 | 之後聊天機器人怎麼用 |
| --- | --- | --- |
| `topics` | 食、衣、住、行、育、樂，加上居留簽證、工作、獎助學金、保險醫療、緊急安全、新生 | LINE 圖文選單分類；檢索時過濾 |
| `identities` | 外籍學位生、交換生、僑生、陸生、訪問研修生；沒提到就是「全體境外生」 | 依學生身分過濾，避免答錯身分 |
| `lang` | zh／en | 用學生提問的語言優先檢索 |
| `risk` | 居留、工作、緊急相關標成 high | 回答時一定附官方連結，必要時轉人工 |
| `deadline_passed` | 有寫期限，而且日期都已經過了 | 不放進知識庫，或標註「已截止」 |
| `possibly_outdated` | 文中最近的年份已是兩年前以前（例如保險頁寫 109-110 年度） | 列入待確認清單，請國際處確認 |

分類關鍵字都在 `taxonomy.py`，要調整分類時改那裡就好。

## 爬蟲遵守的規則

- 會先讀網站的 `robots.txt`，**只爬允許的頁面**。如果網站不允許，程式會停下來並在報告列出原因，請不要繞過。這時候應該請國際處或計中授權，或請單位直接提供檔案。
- 每次請求間隔 2 秒，網站如果有指定更長的間隔，就照網站的設定。
- 只爬 `config.yaml` 裡 `allow` 規則允許的網址，最多 300 頁、3 層連結。
- 有一次一頁都沒抓到時，會保留上一次的結果，不會把好的資料洗掉。

## 常見問題

| 狀況 | 處理方式 |
| --- | --- |
| 報告顯示「robots.txt 不允許」 | 不要繞過。寄信給國際處或計中說明用途、申請授權，或請單位提供檔案 |
| `SSL: CERTIFICATE_VERIFY_FAILED` | 確認已安裝 `truststore`（requirements 裡有）；仍失敗就回報給我 |
| 某些頁面內容很少 | 可能是用 JavaScript 載入，或只是連結集合頁；報告的「內容很少的頁面」會列出來 |
| `.doc`、`.ppt` 舊格式附件沒有文字 | 用 Word 另存成 `.docx` 後放進 `04_知識庫資料/原始資料/手動補充/` |
| 掃描版 PDF 抽不出字 | 報告會列在「需要人工處理的附件」，之後再用 OCR 處理 |
| 想加別的網站 | 在 `config.yaml` 的 `sites` 下面照格式新增一段 |
